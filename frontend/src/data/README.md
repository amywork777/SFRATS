# Neighborhood labels

`sf-neighborhoods.json` contains label points derived on 2026-10-25 from the City and County of San Francisco’s [Analysis Neighborhoods dataset](https://data.sf.gov/Geographic-Locations-and-Boundaries/Analysis-Neighborhoods/j2bu-swwd).

Source GeoJSON: https://data.sfgov.org/resource/j2bu-swwd.geojson

For each of the 41 neighborhoods, the label point is the area centroid of the largest exterior polygon. Names are retained from the `nhood` field. These points label areas, not precise addresses or boundary claims. The map credits DataSF alongside its basemap providers.
